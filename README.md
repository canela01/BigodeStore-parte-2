# BigodeStore-parte-2

🧠 Aprendizados Práticos Adquiridos
Com a mentoria do Professor Bigode, foram explorados e aplicados diversos conceitos cruciais para a formação front-end:

🛠️ Estruturação em HTML5
Tags Semânticas Modernas: Organização de blocos lógicos usando as tags <header>, <nav>, <main>, <section>, <article> e <footer> para melhor rankeamento orgânico (SEO) e acessibilidade.

Hierarquia de Conteúdo: Aplicação correta das tags de título (<h1> até <h3>) de acordo com a relevância na página.

Ancoragem e Links: Criação de caminhos internos e externos fluidos usando a tag <a>.

🎨 Estilização em CSS3
Manipulação do Box Model: Ajustes precisos de margens (margin), preenchimentos (padding) e controle de bordas para espaçamento perfeito dos cards.

Efeitos de Estado (:hover): Animações suaves em botões e cards de jogos para aumentar o engajamento e dar feedback visual ao usuário.

Estilização de Texto e Tipografia: Importação de fontes modernas estilo gamer do Google Fonts e controle de espaçamentos textuais.

Posicionamento de Elementos: Técnicas de alinhamento em bloco e centralização para deixar a interface profissional.
